## 導入・セットアップ

### Q1. インストールに必要なものは何ですか？

**A.** Node.js 20 以上と、npm（または pnpm / bun / yarn）が必要です。また、Supabase プロジェクトと Stripe アカウントをあらかじめ用意してください。

### Q2. 環境変数はどこに設定すればよいですか？

**A.** リポジトリルートの `.env.example` をコピーして `.env.local` を作成し、そこに設定値を記入してください。`.env.local` は `.gitignore` でバージョン管理から除外されています。

### Q3. 開発サーバーはどう起動しますか？

**A.** `npm run dev` を実行し、`http://localhost:3000` にアクセスします。

## 機能・操作

### Q4. BCP 計画はどこで作成できますか？

**A.** `/wizard`（BCP ウィザード）からステップ形式で計画を作成できます。作成した計画は `/dashboard` で一覧・編集できます。

### Q5. PDF 出力は日本語に対応していますか？

**A.** はい、`public/fonts/` に同梱された Noto Sans JP を使用し、日本語の PDF 出力が可能です。

### Q6. 決済機能はどのサービスを使っていますか？

**A.** Stripe を使用しています。`/checkout` から購入フローを利用できます。

### Q7. 認証はどのように行いますか？

**A.** Supabase Auth を使用し、メールアドレスとパスワードによるログイン・サインアップを行います。

## トラブルシューティング

### Q8. ビルド時にエラーが出ます。どうすればよいですか？

**A.** まず `npm run build` のエラーメッセージを確認し、TypeScript の型エラーや依存パッケージの不足がないか確認してください。`npm install` のやり直しや、`node_modules` の削除・再インストールを試すと解決する場合があります。

### Q9. 環境変数が反映されません。

**A.** `.env.local` を修正した後は、開発サーバーを再起動してください。また、変数名のスペルミスや、`NEXT_PUBLIC_` プレフィックスの付け忘れがないか確認してください。

### Q10. PDF が文字化けします。

**A.** `public/fonts/NotoSansJP-{Regular,Bold}.ttf` が正しく配置されているか、およびフォントパスがコードで正しく指定されているか確認してください。
